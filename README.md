# 算法学习记录 🧱

每天上传算法代码，点亮 GitHub 瓷砖墙。

## 目录结构

```
algorithm-learning/
├── README.md          # 本文件
└── daily/             # 每天一题，按日期归档
    └── 2026-10-12.md
```

## 使用方式

每天做完题后，把代码和思路写进当天的文件，然后提交：

```bash
cd algorithm-learning
git add .
git commit -m "2026-10-12 两数之和"
git push
```

## 提交规范

- 提交信息格式：`日期 + 题目名`，例如 `2026-10-12 两数之和`
- 一个提交 = 一天的学习记录，让瓷砖墙每天亮一格
