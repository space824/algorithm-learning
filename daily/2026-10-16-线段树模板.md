线段树是竞赛和面试里绕不开的数据结构，但很多人卡在「会背模板却不会用」。我按一个循序渐进的路给你拆开，跟着走就行。

  一、前置知识

  先把这些确认会了，否则会卡：
  - 递归（线段树的建树/查询几乎都靠递归理解）
  - 二叉树的性质（下标 2x 左儿子、2x+1 右儿子）
  - 分治思想（把一个大区间拆成两半分别处理再合并）
  - 树状数组（BIT）：强烈建议先学。它能做「单点修改 +
  区间查询」，学完后你自然会问「那区间修改怎么办」——答案就是线段树。带着疑问学比干学高效得多。

  二、分四个阶段学

  阶段 1：单点修改 + 区间查询（最核心，先吃透）

  这是线段树的「母题」，本质是维护一个满足结合律的信息（和、最大值、最小值、gcd……），支持：
  - point_update(pos, val)
  - range_query(l, r)

  先手写一个「区间求和」的完整模板，能默写且讲清楚每个 return 的含义，再往下走。

  阶段 2：区间修改 + 懒标记（lazy propagation）

  这是第一个大坎。核心理解一句话：

  ▎ 懒标记（tag）表示「这个节点整体应该加的值，但我还没往下推给儿子」。
  ▎ 查询/修改一旦要进入这个节点的儿子，就先把 tag 下推（pushdown），自己清零。

  务必画图理解 pushup / pushdown / modify 三个函数如何配合。这个阶段常错的点：
  - 修改后忘记 pushup
  - 进入儿子前忘记 pushdown
  - query 里也忘了 pushdown（新手最容易漏）

  阶段 3：多种信息 / 多懒标记

  一个节点维护多个字段、多个 tag 时，关键是搞清标记的下推顺序：
  - 经典题：区间加 + 区间乘，同时维护区间和（tag 要分 add 和 mul，下推顺序有讲究）
  - 区间加 + 区间赋值
  - 区间求最大子段和（每个节点维护 4 个值：sum、lmax、rmax、max）

  到这一步你才算真的「理解」了线段树，而不是背板。

  阶段 4：进阶变体（按需选学）

  - 动态开点：值域很大（如 1e9）时不用数组开满
  - 权值线段树：维护值域上的数量，可做「第 k 小」
  - 线段树合并 / 可持久化（主席树）：树上问题、历史版本
  - zkw 线段树：非递归、常数小，但先别碰，会打乱你对递归版的理解

  三、一个极简模板（C++，区间求和 + 区间加）

  struct SegTree {
      int n;
      vector<long long> sum, tag;  // tag = 懒标记

      SegTree(vector<int>& a) {
          n = a.size();
          sum.assign(4 * n, 0);
          tag.assign(4 * n, 0);
          build(1, 0, n - 1, a);
      }

      void build(int p, int l, int r, vector<int>& a) {
          if (l == r) { sum[p] = a[l]; return; }
          int mid = (l + r) >> 1;
          build(p << 1, l, mid, a);
          build(p << 1 | 1, mid + 1, r, a);
          sum[p] = sum[p << 1] + sum[p << 1 | 1];
      }

      void apply(int p, int l, int r, long long v) {
          sum[p] += v * (r - l + 1);
          tag[p] += v;
      }

      void pushdown(int p, int l, int r) {
          int mid = (l + r) >> 1;
          apply(p << 1, l, mid, tag[p]);
          apply(p << 1 | 1, mid + 1, r, tag[p]);
          tag[p] = 0;
      }

      void range_add(int ql, int qr, long long v) { range_add(1, 0, n - 1, ql, qr, v); }
      void range_add(int p, int l, int r, int ql, int qr, long long v) {
          if (ql <= l && r <= qr) { apply(p, l, r, v); return; }
          pushdown(p, l, r);
          int mid = (l + r) >> 1;
          if (ql <= mid) range_add(p << 1, l, mid, ql, qr, v);
          if (qr > mid)  range_add(p << 1 | 1, mid + 1, r, ql, qr, v);
          sum[p] = sum[p << 1] + sum[p << 1 | 1];
      }

      long long range_sum(int ql, int qr) { return range_sum(1, 0, n - 1, ql, qr); }
      long long range_sum(int p, int l, int r, int ql, int qr) {
          if (ql <= l && r <= qr) return sum[p];
          pushdown(p, l, r);
          int mid = (l + r) >> 1;
          long long res = 0;
          if (ql <= mid) res += range_sum(p << 1, l, mid, ql, qr);
          if (qr > mid)  res += range_sum(p << 1 | 1, mid + 1, r, ql, qr);
          return res;
      }
  };

  五、几个关键认知（帮你少走弯路）

  1. 线段树 ≠ 只能求和。它维护的是「可合并的信息」。先想清楚「两个小区间的答案怎么合并成一个大区间的答案」，再去写代码。
  2. 能离线 + 区间修改，优先想差分。有些题看着要线段树，其实差分数组/树状数组更快更简单，别陷入「有线段树就无脑套」。
  3. 数组开 4 倍（4 * n）是通用安全值，不用纠结为什么（严格是 2^(ceil(log n)+1)，背 4n 就行）。
  4. 先画图，再写码。每个新变体先在纸上画出一棵 4 节点的树，模拟一次 pushdown，比自己瞎想快得多。
